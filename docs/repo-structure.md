# Repository Structure

## Main folders

- `main/`: final group submission
  - `phase-1/`: Labs 12, 12a, and 12b
  - `phase-2/`: Labs 12c and 12d
- `members/`: individual participant work
- `shared/`: shared templates and diagrams
- `docs/`: team documentation

## Root files

- `README.md`: project overview and navigation
- `CONTRIBUTING.md`: contribution and pull-request rules
- `.gitignore`: excluded local, secret, Terraform, and generated files
